О проекте

Исследовательский стенд для изучения устойчивости водяных знаков

Что исследуется

Проект анализирует устойчивость невидимых цифровых водяных знаков (в частности, Google SynthID) к типичным операциям обработки изображений.

SynthID встраивает водяной знак в частотные компоненты изображения. В отличие от стеганографии на основе LSB, он выживает при JPEG-сжатии, ресайзе и скриншотах.

Стек
HTML5 Canvas API — обработка пикселей в браузере
JS Vanilla JS — без зависимостей
CSS CSS-переменные, адаптивная сетка
Метрики PSNR, SSIM, MAE — вычисляются локально
Методология
01
LSB XOR
Модифицирует бит 0 каждого канала RGB. Визуально идентично оригиналу (PSNR ~55 dB), но меняет бинарные паттерны водяного знака.
02
Кроп + Ресайз
Удаляет N% краёв, масштабирует обратно бикубикой. Нарушает пространственное расположение паттернов водяного знака.
03
JPEG-пересжатие
DCT-квантование разрушает высокочастотные компоненты. При Q=60–70 паттерны водяного знака деградируют ниже порога детекции.
04
Color Jitter
Добавляет случайный шум ±N. При ±1–2 невидимо глазу, при этом изменяет статистику цветовых каналов.
05
Upscale → Downscale
Интерполяция при увеличении смешивает пиксели, создавая новые промежуточные значения. Повторный ресайз вниз разрушает паттерны.
