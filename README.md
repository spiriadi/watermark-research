# Watermark Robustness Research Stand

Исследовательский стенд для анализа устойчивости цифровых водяных знаков (SynthID и др.) к методам обработки изображений.

## Запуск

Просто откройте `index.html` в браузере — зависимостей нет, интернет не нужен.

## Структура

```
watermark-research/
├── index.html          # Главная страница
├── css/
│   └── style.css       # Стили (light/dark mode)
├── js/
│   ├── processor.js    # Алгоритмы обработки + метрики
│   └── app.js          # UI-логика, оркестрация пайплайна
└── README.md
```

## Пайплайн

| Шаг | Метод | Параметры |
|-----|-------|-----------|
| 01 | LSB XOR | seed 1–9999 |
| 02 | Кроп + ресайз + сдвиг | crop 1–10%, shiftX/Y 0–15px |
| 03 | JPEG-пересжатие | quality 30–95 |
| 04 | Color Jitter | delta ±1–10 |
| 05 | Upscale → Downscale | factor x2–x4 |

## Метрики

- **PSNR** (Peak Signal-to-Noise Ratio) — измеряет уровень шума в dB. > 40 dB: визуально идентично.
- **SSIM** (Structural Similarity Index) — структурное сходство 0..1. > 0.97: отличное.
- **MAE** (Mean Absolute Error) — средняя абсолютная ошибка на пиксель.

## Технологии

- HTML5 Canvas API — вся обработка в браузере, данные не покидают устройство
- Vanilla JS — без зависимостей
- CSS custom properties — автоматический dark mode
